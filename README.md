# Lab 7 — Bootstrap 5 Professional Admin Dashboard

A responsive university administration dashboard built for Web Technologies Lab 7.

## Features
- Bootstrap 5 responsive grid, navbar and offcanvas sidebar
- Dashboard KPI cards and recent-student table
- Students page with search, status filter, reset and Bootstrap modal form
- Courses page with course cards
- Attendance page with selectable attendance and confirmation alert
- Reports page with summary cards, department table and progress bars
- Custom CSS combined with Bootstrap utility classes

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser, or run the folder through XAMPP/Apache.
3. Internet connection is required for the Bootstrap CDN stylesheet and JavaScript bundle.

## GitHub Pages
Upload the contents of this folder (not the ZIP file). Keep `index.html` at the repository root, with `assets/` beside it. Then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Note
This is a frontend demonstration using sample data. The add-student and attendance actions are client-side demonstrations; they are not connected to a backend database.
