# Lab 7 Report — Bootstrap 5: Professional Admin Dashboard

## Objective
To use Bootstrap grid and components, create a responsive dashboard, use tables, cards, modals, alerts and forms, and combine Bootstrap with custom CSS.

## Tools
- HTML
- Bootstrap 5
- JavaScript
- Custom CSS
- Browser DevTools

## Implementation
The project converts the student-management interface into a university admin dashboard. It includes a navbar and responsive offcanvas/sidebar navigation, KPI cards, a responsive student table, a modal add-student form, alert messages, course cards, attendance controls and a reports page with summary cards and tables. Bootstrap utility classes are used for spacing, layout and responsive behavior before custom CSS.

## Result
A responsive multi-page admin dashboard was created with Dashboard, Students, Courses, Attendance and Reports pages. The student search and status filter, modal form submission and attendance confirmation provide frontend interactions.

## Problems and Solutions
- **Bootstrap styles missing:** verify the Bootstrap CDN link and internet connection.
- **Modal does not open:** ensure the Bootstrap JavaScript bundle is included before the custom script.
- **Layout overflow:** inspect Bootstrap container, row and column nesting and use responsive table wrappers.

## Evidence to Attach
1. Dashboard showing KPI cards and sidebar.
2. Students page showing the add-student modal.
3. Attendance page or Reports page showing the table and summary cards.

## Conclusion
The lab demonstrates how Bootstrap 5 components and responsive utilities can be combined with custom CSS to build a professional admin dashboard.

## Limitation
This is a frontend-only sample. Data is illustrative and is not persisted to a server/database.
